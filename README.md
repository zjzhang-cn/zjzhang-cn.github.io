# zjzhang-cn.github.io

Source of <https://zjzhang-cn.github.io/> — a real-time Three.js scene of 太和殿
(Taihe Hall, the Forbidden City).

The site files (`index.html`, `app.js`, `styles.css`) are built from
[zjzhang-cn/taihe-hall](https://github.com/zjzhang-cn/taihe-hall). To update the
live site, rebuild there with `npm run build` and copy those three files into
the repository root.
